## 📌 Project Overview
This repository contains a production-ready **Hybrid Movie Recommendation Engine** built using the MovieLens 1M dataset. 

In real-world recommendation systems, single-algorithm approaches often fail. Pure Collaborative Filtering struggles with brand-new users or movies (the "cold-start" problem), while pure Content-Based Filtering often traps users in a "filter bubble" by only recommending items identical to what they have already seen. 

To solve these limitations, this project implements a dynamic **Hybrid Architecture** that calculates a weighted aggregate score using three distinct methodologies: Matrix Factorization (SVD), TF-IDF Vectorization, and Bayesian Statistics.

The codebase is strictly modularized, separating the heavy data-processing and model-training phases from the lightweight inference API, following standard machine learning engineering best practices.

## 🧠 The Machine Learning Architecture

To generate highly personalized Top-N recommendations, the system calculates a weighted `Hybrid Score` for unseen movies based on three distinct components:

### 1. Collaborative Filtering (Matrix Factorization via SVD)
* **How it works:** This component learns the latent (hidden) interactions between users and movies. By factoring the user-item rating matrix, the model can predict how a user would rate a movie based on the behavior of similar users.
* **Implementation:** Built using `scikit-surprise`'s Singular Value Decomposition (SVD). Hyperparameters (learning rate, regularization, epochs) were aggressively tuned using `GridSearchCV` with 3-fold cross-validation to prevent overfitting.
* **Strengths:** Highly accurate for active users with established viewing histories.

### 2. Content-Based Filtering (TF-IDF Cosine Similarity)
* **How it works:** This component recommends movies by analyzing the metadata of what the user has previously liked. 
* **Implementation:** A custom feature-engineering pipeline combines movie titles, release decades, and genres (weighted heavily) into a single document profile. A `TfidfVectorizer` transforms these profiles into a sparse matrix, and `linear_kernel` computes the cosine similarity between items.
* **Strengths:** Crucial for handling new or obscure movies that lack enough user ratings for SVD to process.

### 3. The Popularity Baseline (Bayesian Weighted Average)
* **How it works:** Standard popularity metrics are flawed—a movie with a single 5-star rating will mathematically beat a masterpiece with thousands of 4.8-star ratings. 
* **Implementation:** This model utilizes a **Bayesian Average** formula: `(v / (v + m)) * R + (m / (v + m)) * C`, which pulls the ratings of movies with very few votes toward the global mean, establishing a statistically sound and fair popularity baseline.
* **Strengths:** Acts as the ultimate safety net for brand-new users (Cold-Start handling) who have zero interaction history.

### ⚖️ The Hybrid Aggregation
The final recommendation list is generated by normalizing the outputs of all three models to a `0-1` scale and computing a final weighted score:
`Hybrid Score = (α * SVD_Score) + (β * CBF_Score) + (γ * Popularity_Score)`
